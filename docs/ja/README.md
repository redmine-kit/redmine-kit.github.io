## セキュリティ

脆弱性は、公開の Issue や Pull Request では報告しないでください。GitHub のプライベート脆弱性レポートを使います。該当するリポジトリの **Security** タブを開き、**Report a vulnerability** を選びます。[セキュリティポリシー](https://github.com/redmine-kit/.github/blob/main/SECURITY.md)を参照してください。
